# 실측 리포트

실기기 주행에서 나온 증상과 그 원인을 정리한 문서다. 브라우저로 바로 열린다
(외부 의존은 Google Fonts 하나뿐이고, 없어도 대체 글꼴로 읽힌다).

계획 문서(`../pdr-*.md`)와 성격이 다르다. 여기 있는 것은 **그날 그 기기에서 실제로
나온 숫자**이고, 고친 뒤에도 지우지 않는다 — 상수를 왜 그 값으로 잡았는지 묻는
사람이 돌아올 자리다.

| 날짜 | 문서 | 무엇 |
|---|---|---|
| 2026-08-20 | [실측 6건 원인 분석](2026-08-20-실측-6건-원인-분석.html) | 스크린샷 7장에서 나온 증상 6건. 코드 근거가 있는 것과 가설을 갈라 정리했고, 5번은 2차 실측으로 다시 썼다 |
| 2026-08-20 | [실내·실외 전환 해부](2026-08-20-실내-실외-전환-해부.html) | GPS 표본 193건으로 본 출입 판정. 정확도가 문 근처에서 나빠지는 것, 문 노드가 GPS를 12초 앞선 것, 재진입 25초 공백 |
| 2026-08-21 | [실측 세 바퀴](2026-08-21-실측-세-바퀴-정리.html) | 세 라운드 18건을 한 장으로. 실측 숫자가 어떤 판단을 뒤집었는지와, 다음 주행이 있어야 답이 나오는 것들 |

## 원본 세션 JSON

문서의 숫자는 `pdr-debug-session` JSON(schema v16~v20)에서 뽑았다. 파일 자체는
용량 때문에 저장소에 넣지 않는다 — 필요하면 그날 주행을 한 사람에게 받는다.
스키마는 [pdr-dev-integration.md](../pdr-dev-integration.md)가 단일 출처다.
